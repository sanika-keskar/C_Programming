# C Programming – Assignment 6

## Description
This repository contains five C programs that demonstrate functions, pointers, conditional statements, arithmetic operations, and validation of user input.

## Programs Included

1. **Calculate Electricity Bill** – Accepts electricity units consumed and calculates the bill amount based on the unit range.
2. **Check Admission** – Checks student admission eligibility based on marks and age, and identifies invalid inputs.
3. **Calculate Discount** – Calculates the final payable amount after applying a discount based on the purchase amount.
4. **Check Triangle** – Accepts three side lengths and checks whether they form a valid triangle.
5. **Calculate Bonus** – Calculates an employee's bonus based on salary and years of service.

## Concepts Covered
- Functions
- Pointers
- `if-else` statements
- Nested conditional statements
- Logical operators (`&&`, `||`)
- Relational operators (`>`, `<`, `>=`, `<=`)
- Arithmetic operations
- Percentage calculations
- Input validation
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   ```bash
   gcc filename.c -o output
   ```

5. Run the program on Windows:

   ```bash
   .\output.exe
   ```

   Replace `filename.c` with the name of your C source file.

## Learning Objective
The objective of this assignment is to strengthen C programming skills through practical implementation of functions, pointers, decision-making, mathematical calculations, and input validation.
