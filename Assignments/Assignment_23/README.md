
C Programming – Assignment 23


Description

This repository contains five C programs based on advanced string operations and character transformations.

Programs Included

1. Convert String to Lowercase (strlwrx) – Accepts a string from the user and converts all uppercase characters to lowercase in place.
2. Convert String to Uppercase (struprx) – Accepts a string from the user and converts all lowercase characters to uppercase in place.
3. Toggle String Case (strtogglex) – Accepts a string from the user and toggles its case (lowercase to uppercase and vice versa).
4. Display Only Digits (DisplayDigit) – Accepts a string from the user and extracts and prints only the numeric digits.
5. Count White Spaces (CountWhite) – Accepts a string from the user and returns the total number of blank spaces.

Concepts Covered

• User-defined functions
• while loop string traversal
• Pointer handling (char *str)
• ASCII values subtraction/addition for case conversion
• Conditional filtering statements
• Null character (\0) handling
• Custom string input using scanf("%[^'\n']s", arr)
• Output formatting using printf()

Technologies Used

• Programming Language: C
• Compiler: GCC
• Editor: Visual Studio Code / Visual Studio

How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:bash
gcc filename.c -o output
Use code with caution.
4. Run the program on Windows:bash
.\output.exe
Use code with caution.

Learning Objective

The objective of this assignment is to master string manipulation techniques, understand custom case transformations using ASCII values, and practice processing string boundaries efficiently using pointers.
