
C Programming – Assignment 25


Description

This repository contains five C programs dedicated to character category validations and case-insensitive menu/schedule parsing.

Programs Included

1. Check Alphabet Type (ChkAlpha) – Verifies if an inputted character is a valid alphabet letter (A-Z or a-z).
2. Check Capital Case (ChkCapital) – Validates if an isolated character entry is an uppercase letter.
3. Check Digit Entry (ChkDigit) – Scans and confirms if an input value lies within the numeric range (0-9).
4. Check Small Case (ChkSmall) – Checks if a single character parameter belongs to a lowercase sequence.
5. Display Exam Schedule (DisplaySchedule) – Accepts a school division parameter (A, B, C, D) case-insensitively and maps it to a specific time.

Concepts Covered

• Boolean returns (TRUE / FALSE)
• Range validations using logical operator combinations (&& / ||)
• Base ASCII checks for raw values
• Conditional path blocks (if-else if-else)
• Case-insensitivity normalization rules
• Standard terminal data stream capturing

Technologies Used

• Programming Language: C
• Compiler: GCC
• Editor: Visual Studio Code / Visual Studio

How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:bash
gcc filename.c -o output
Use code with caution.
4. Run the program on Windows:bash
.\output.exe
Use code with caution.

Learning Objective

The objective of this assignment is to secure single-character logic control blocks, configure range validators without integrated utility macros, and program input sanitization pathways.
