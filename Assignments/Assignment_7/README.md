# C Programming – Assignment 7

## Description
This repository contains five C programs that demonstrate functions, loops, conditional statements, and arithmetic operations.

## Programs Included

1. **Pattern** – Prints `*` and `$` repeatedly up to the given number.
2. **Display Numbers** – Accepts a number and prints numbers from 1 to that number.
3. **Number Line** – Prints numbers from `-N` to `N`.
4. **Display Odd Numbers** – Accepts `N` and prints all odd numbers up to `N`.
5. **Multiple Display** – Accepts a number and prints its first five multiples.

## Concepts Covered
- User-defined functions
- `for` loop
- Conditional statements (`if`)
- Integer variables
- Arithmetic operators
- Increment operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   ```bash
   gcc filename.c -o output
   ```

5. Run the program on Windows:

   ```bash
   .\output.exe
   ```

   Replace `filename.c` with the name of your C source file.

## Learning Objective
The objective of this assignment is to strengthen C programming skills through practical implementation of loops, functions, number patterns, odd numbers, and multiplication tables.
