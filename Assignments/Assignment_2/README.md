# C Programming – Assignment No 2

This folder contains five basic C programs practiced to understand functions, loops, conditional statements, and return types.

## Programs Included

1. **Display Star Pattern** – Accepts a number from the user and prints the `*` symbol that many times using a `while` loop.

2. **Hello or Demo** – Accepts a number and prints `Hello` if the number is less than 10; otherwise, it prints `Demo`.

3. **Display Number Multiple Times** – Accepts a number and a frequency, then prints the given number according to the specified frequency using a `for` loop.

4. **Check Even or Odd** – Accepts a number and checks whether it is even or odd using an `if-else` statement.

5. **Display Number** – Accepts a number from the user and displays it using a function.

## Concepts Covered

- Functions in C
- User input using `scanf()`
- Output using `printf()`
- `while` and `for` loops
- `if-else` conditional statements
- Basic data types and variables
- Function parameters and return types

## Language Used

- C Programming Language

## Purpose

These programs help build a strong foundation in C programming by practicing basic logic, loops, conditions, and functions.
