# Assignment 1 – C Programming

## Description
This folder contains basic C programs demonstrating functions, loops, conditional statements, and arithmetic operations.

## Programs Included
1. **Division** – Performs division of two integers and handles division by zero.
2. **Display Marvellous** – Prints "Marvellous" five times.
3. **Display Numbers** – Displays numbers from 5 to 1 using a `while` loop.
4. **Check Divisibility** – Checks whether a number is divisible by 5.
5. **Accept and Display** – Prints five asterisk (`*`) characters on the screen.

## Concepts Covered
- User-defined functions
- `for` and `while` loops
- Conditional statements (`if-else`)
- Function parameters and return values
- Basic arithmetic operations
