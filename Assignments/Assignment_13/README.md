# C Programming – Assignment 13

## Description
This repository contains five C programs based on digit counting and arithmetic operations.

## Programs Included

1. **Count Even Digits** – Counts the even digits in a given number.
2. **Count Odd Digits** – Counts the odd digits in a given number.
3. **Count Range Digits** – Counts digits between 3 and 7.
4. **Multiply Digits** – Calculates the multiplication of all digits in a number.
5. **Even and Odd Difference** – Finds the difference between the sum of even digits and odd digits.

## Concepts Covered
- User-defined functions
- `while` loop
- Conditional statements (`if-else`)
- Integer variables
- Modulus operator (`%`)
- Division operator (`/`)
- Digit extraction
- Arithmetic operations
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to improve understanding of digit counting, multiplication, and addition using loops and conditional statements.
