
C Programming – Assignment 27


Description

This repository contains five C programs for analyzing textual character content distributions, vowel structures, and string processing trends.

Programs Included

1. Count Capital Characters (CountCapital) – Counts the quantity of uppercase alphabetic letters enclosed in an array.
2. Count Small Characters (CountSmall) – Gathers the cumulative frequency of lowercase text members.
3. Difference Frequency (Difference) – Computes the net mathematical difference between lowercase and uppercase letter frequencies.
4. Check Vowels Presence (ChkVowel) – Scans text parameters case-insensitively to report whether any vowel targets reside inside.
5. Display String in Reverse Order (Reverse) – Processes string instances utilizing pointers to display the text inverted on the console screen without editing original variables.

Concepts Covered

• Frequency metrics evaluation
• Linear counter manipulation variables
• Offset variance computation logic (iSmallCount - iCapitalCount)
• Logical evaluations targeting character blocks
• Indirect string pointer adjustments (end--)
• Null safety filters (str == NULL)

Technologies Used

• Programming Language: C
• Compiler: GCC
• Editor: Visual Studio Code / Visual Studio
