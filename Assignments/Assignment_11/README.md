# C Programming – Assignment 11

## Description
This repository contains five C programs based on number ranges and loops.

## Programs Included

1. **Range Display** – Displays all numbers between two given numbers.
2. **Even Numbers** – Displays all even numbers in a given range.
3. **Range Sum** – Calculates the addition of all numbers in a given positive range.
4. **Even Range Sum** – Calculates the addition of all even numbers in a given positive range.
5. **Reverse Range Display** – Displays all numbers in a given range in reverse order.

## Concepts Covered
- User-defined functions
- `for` loop
- Conditional statements (`if`)
- Integer variables
- Arithmetic operators
- Range checking
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to improve understanding of loops, number ranges, even numbers, and addition using C programming.
