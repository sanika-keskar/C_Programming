# C Programming – Assignment 8

## Description

This repository contains five C programs that demonstrate functions, loops, conditional statements, arithmetic operations, and number handling.

## Programs Included

1. **Check Number Size** – Accepts a number and displays Small if it is less than 50, Medium if it is between 50 and 100, or Large if it is greater than 100.
2. **Display Number in Words** – Accepts a single-digit number and displays it in words. Negative single-digit numbers are also supported, while multi-digit numbers are reported as invalid.
3. **Calculate Factorial** – Accepts a number and calculates its factorial using a loop. Negative inputs are handled using their absolute value.
4. **Display Multiplication Table** – Accepts a number and displays its multiplication table from 1 to 10.
5. **Display Reverse Multiplication Table** – Accepts a number and displays its multiplication table in reverse order, from 10 to 1.

## Concepts Covered

- Functions
- `for` loops
- `if-else` statements
- Nested conditional statements
- Relational operators (`<`, `>`, `<=`, `>=`)
- Arithmetic operators (`*`, `-`)
- Factorial calculation
- Multiplication tables
- Number handling using absolute values
- Returning values from functions
- User input using `scanf()`
- Output using `printf()`

## Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   `gcc filename.c -o output`
5. Run the program on Windows:

   `.\output.exe`

   Replace `filename.c` with the name of your C source file.

## Learning Objective

The objective of this assignment is to improve basic C programming skills through practical implementation of functions, conditional logic, loops, factorial calculations, multiplication tables, and number handling.
