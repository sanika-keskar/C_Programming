# C Programming – Assignment 19

## Description
This repository contains five C programs based on triangle and number patterns.

## Programs Included

1. **Increasing Triangle** – Displays stars in an increasing triangle pattern.
2. **Decreasing Triangle** – Displays stars in a decreasing triangle pattern.
3. **Symbol Triangle** – Displays $, #, and * symbols in a triangle pattern.
4. **Star Pattern** – Displays stars in a pattern with full first and last rows.
5. **Decreasing Column Pattern** – Displays numbers in decreasing columns.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Conditional statements (`if-else`)
- Triangle patterns
- Number patterns
- Symbol patterns
- Row and column operations
- Increment and decrement operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand triangle patterns, nested loops, and number arrangements using C programming.
