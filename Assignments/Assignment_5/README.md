# C Programming – Assignment 3

## Description
This repository contains five C programs that demonstrate functions, pointers, conditional statements, relational operators, and character handling.

## Programs Included

1. **Find Greatest** – Accepts three integers and identifies the greatest number.
2. **Check Leap Year** – Accepts a year and checks whether it is a leap year.
3. **Display Grade** – Accepts student marks and displays the corresponding grade.
4. **Check Multiple Divisibility** – Checks whether a number is divisible by both 3 and 5.
5. **Check Character Type** – Identifies whether an entered character is an uppercase letter, lowercase letter, digit, or special symbol.

## Concepts Covered
- Functions
- Pointers
- `if-else` statements
- Nested conditional statements
- Relational operators (`>`, `<`, `>=`, `<=`)
- Logical AND operator (`&&`)
- Modulus operator (`%`)
- Character handling
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   ```bash
   gcc filename.c -o output
   ```

5. Run the program on Windows:

   ```bash
   .\output.exe
   ```

   Replace `filename.c` with the name of your C source file.

## Learning Objective
The objective of this assignment is to improve basic C programming skills through practical implementation of functions, pointers, conditional logic, arithmetic operations, and character classification.
