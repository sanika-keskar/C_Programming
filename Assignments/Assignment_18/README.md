# C Programming – Assignment 18

## Description
This repository contains five C programs based on star, hash, and number patterns.

## Programs Included

1. **Increasing Star Pattern** – Displays stars and hashes in an increasing pattern.
2. **Decreasing Star Pattern** – Displays stars and hashes in a decreasing pattern.
3. **Diagonal Pattern** – Displays a dollar ($) symbol diagonally with stars.
4. **Border Pattern** – Displays stars on the border and @ symbols inside.
5. **Number Border Pattern** – Displays numbers on the border and stars inside.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Conditional statements (`if-else`)
- Number patterns
- Symbol patterns
- Row and column operations
- Comparison operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand nested loops and create different patterns using stars, hashes, numbers, and special symbols.
