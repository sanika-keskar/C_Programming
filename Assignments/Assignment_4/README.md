# C Programming – Assignment 4

## Description
This repository contains five basic C programs that demonstrate functions, conditional statements, comparison operators, and decision-making in C.

## Programs Included

1. **Check Number** – Accepts an integer and determines whether it is positive, negative, or zero.
2. **Check Even Odd** – Accepts a number and checks whether it is even or odd.
3. **Find Greater** – Accepts two integers and identifies the greater number.
4. **Check Voting Eligibility** – Accepts a person's age and checks whether they are eligible to vote.
5. **Check Divisibility** – Accepts an integer and checks whether it is divisible by 5.

## Concepts Covered
- Functions
- `if-else` statements
- Nested `if-else` conditions
- Comparison operators (`>`, `<`, `>=`)
- Modulus operator (`%`)
- User input using `scanf()`
- Output using `printf()`
- Basic decision-making logic

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   ```bash
   gcc filename.c -o output
   ```

5. Run the program on Windows:

   ```bash
   .\output.exe
   ```

   Replace `filename.c` with the name of your C source file.

## Learning Objective
The objective of this assignment is to strengthen basic C programming skills through practical implementation of functions, conditional statements, and logical operations.
