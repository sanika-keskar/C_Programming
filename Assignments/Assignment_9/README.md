# C Programming – Assignment 9

## Description
This repository contains five C programs that demonstrate functions, loops, and arithmetic operations.

## Programs Included

1. **Display Pattern** – Prints stars (*) and hashes (#) according to the given number.
2. **Dollar to INR** – Converts US dollars into Indian rupees.
3. **Even Factorial** – Calculates the multiplication of even numbers up to the given number.
4. **Odd Factorial** – Calculates the multiplication of odd numbers up to the given number.
5. **Factorial Difference** – Finds the difference between even factorial and odd factorial.

## Concepts Covered
- User-defined functions
- `for` loop
- Integer variables
- Arithmetic operators
- Conditional statements
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand functions, loops, factorial calculations, and basic arithmetic operations.
