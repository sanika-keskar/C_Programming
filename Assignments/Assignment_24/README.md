
C Programming – Assignment 24


Description

This repository contains five C programs focusing on string search operations, character frequency analysis, and structural array modifications.

Programs Included

1. Check Character Presence (ChkChar) – Accepts a string and a target character, then checks whether the character is present.
2. Count Character Frequency (CountChar) – Accepts a string and a character, returning the total frequency of that specific character.
3. First Occurrence Index (FirstChar) – Finds and returns the first positional index (0-indexed) of a character in a string, returning -1 if not found.
4. Last Occurrence Index (LastChar) – Finds and returns the last positional index of a character in a string, returning -1 if not found.
5. Reverse String In-Place (StrRevX) – Swaps characters internally to reverse the user-inputted string in memory without utilizing an extra buffer.

Concepts Covered

• String traversal algorithms
• Target tracking with index counters
• Dual-pointer swapping mechanisms (start and end tracking)
• Position marking and tracking loops
• Custom Boolean type management (typedef int BOOL)
• Multi-parameter function execution
• Pointer termination checks

Technologies Used

• Programming Language: C
• Compiler: GCC
• Editor: Visual Studio Code / Visual Studio

Learning Objective

The objective of this assignment is to understand positional tracking in linear search setups, explore structural updates to string layouts using double pointers, and build effective search routines.
