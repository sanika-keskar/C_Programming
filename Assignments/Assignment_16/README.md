# C Programming – Assignment 16

## Description
This repository contains five C programs that display different patterns using alphabets and numbers.

## Programs Included

1. **Alphabet Pattern** – Displays capital alphabets from A onwards in each row.
2. **Capital and Small Letters** – Displays capital and small alphabets in alternate rows.
3. **Same Alphabet Pattern** – Displays the same alphabet repeatedly in each row.
4. **Decreasing Number Pattern** – Displays numbers in decreasing order row-wise.
5. **Continuous Number Pattern** – Displays continuous numbers in rows and columns.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Alphabet printing
- Number patterns
- Character variables
- Integer variables
- Increment operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand nested loops and learn how to create different alphabet and number patterns using C programming.
