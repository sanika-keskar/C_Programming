# C Programming – Assignment 3

## Description
This repository contains five basic C programs that demonstrate functions, loops, pointers, conditional statements, and character operations.

## Programs Included

1. **Print Even Numbers** – Accepts a number from the user and prints that many even numbers using a `for` loop.
2. **Display Even Factors** – Accepts an integer and displays all its even factors.
3. **Display Factor (Even Factors)** – Uses a pointer and conditional statements to display the even factors of a given number.
4. **Display Convert** – Accepts a character and converts lowercase letters to uppercase and uppercase letters to lowercase.
5. **Check Vowel** – Accepts a character and checks whether it is a vowel (`a`, `e`, `i`, `o`, `u`) or not. It supports both uppercase and lowercase vowels.

## Concepts Covered
- Functions
- `for` loops
- `if-else` statements
- Pointers
- Character handling
- Modulus operator (`%`)
- User input using `scanf()`
- Output using `printf()`
- Boolean-style return values using `TRUE` and `FALSE`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Clone or download this repository.
2. Open the program folder in Visual Studio Code.
3. Open the terminal.
4. Compile the required C file:

   ```bash
   gcc filename.c -o output
   ```

5. Run the program on Windows:

   ```bash
   .\output.exe
   ```

   Replace `filename.c` with the name of your C source file.

## Learning Objective
The objective of this assignment is to strengthen basic C programming skills through practical implementation of functions, loops, pointers, and conditional logic.
