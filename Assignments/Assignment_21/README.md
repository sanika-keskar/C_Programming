# C Programming – Assignment 21

## Description
This repository contains five C programs based on simple number and symbol patterns.

## Programs Included

1. **Star Pattern** – Displays stars in rows and columns.
2. **Number Pattern** – Displays numbers from 1 to the given number of columns.
3. **Reverse Number Pattern** – Displays numbers in decreasing order.
4. **Alternate Symbol Pattern** – Displays stars (*) and hashes (#) alternately.
5. **Row Number Pattern** – Displays the same row number repeatedly in each row.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Number patterns
- Symbol patterns
- Conditional statements (`if-else`)
- Increment and decrement operators
- Row and column operations
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand nested loops and create simple number and symbol patterns using C programming.
