# C Programming – Assignment 22

## Description
This repository contains five C programs based on alphabets, numbers, and symbols.

## Programs Included

1. **Alphabet Pattern** – Displays capital alphabets from A onwards.
2. **Reverse Number Pattern** – Displays numbers in decreasing order with hash (#) symbols.
3. **Number and Star Pattern** – Displays numbers with stars (*) alternately.
4. **Mixed Symbol Pattern** – Displays hashes (#), numbers, and stars (*) in a pattern.
5. **Even Number Pattern** – Displays even numbers up to the given number of elements.

## Concepts Covered
- User-defined functions
- `for` loop
- Integer and character variables
- Number patterns
- Alphabet patterns
- Conditional statements
- Arithmetic operators
- Increment and decrement operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to improve understanding of functions, loops, alphabets, numbers, and symbol patterns using C programming.
