# C Programming – Assignment 20

## Description
This repository contains five C programs based on diagonal, symbol, and number patterns.

## Programs Included

1. **Diagonal Hash Pattern** – Displays a hash (#) symbol diagonally with stars.
2. **Symbol Pattern** – Displays *, #, and @ symbols in a pattern.
3. **Star Pattern** – Displays stars in a pattern with full first and last rows.
4. **Mixed Symbol Pattern** – Displays stars, hashes, and dollar symbols in a pattern.
5. **Number Pattern** – Displays numbers in a special row and column pattern.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Conditional statements (`if-else`)
- Diagonal patterns
- Symbol patterns
- Number patterns
- Row and column operations
- Comparison operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to improve logical thinking and understand different diagonal, symbol, and number patterns using nested loops.
