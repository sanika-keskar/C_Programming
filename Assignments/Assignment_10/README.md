# C Programming – Assignment 10

## Description
This repository contains five C programs based on mathematical calculations and unit conversions.

## Programs Included

1. **Circle Area** – Calculates the area of a circle using its radius.
2. **Rectangle Area** – Calculates the area of a rectangle using width and height.
3. **KM to Meter** – Converts kilometres into metres.
4. **Fahrenheit to Celsius** – Converts temperature from Fahrenheit into Celsius.
5. **Square Feet to Square Meter** – Converts square feet into square metres.

## Concepts Covered
- User-defined functions
- Float and double variables
- Arithmetic operators
- Mathematical formulas
- Unit conversion
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand mathematical formulas, arithmetic operations, and different unit conversions using C programming.
