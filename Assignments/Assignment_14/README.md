# C Programming – Assignment 14

## Description
This repository contains five C programs based on factors of numbers and arithmetic operations.

## Programs Included

1. **Multiplication of Factors** – Calculates the multiplication of all factors of a given number.
2. **Reverse Factors** – Displays all factors of a number in decreasing order.
3. **Non-Factors** – Displays all numbers that are not factors of a given number.
4. **Sum of Non-Factors** – Calculates the sum of all non-factors.
5. **Factor Difference** – Finds the difference between the sum of factors and non-factors.

## Concepts Covered
- User-defined functions
- `for` loop
- Conditional statements (`if-else`)
- Integer variables
- Modulus operator (`%`)
- Multiplication and addition
- Factor checking
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand factors, non-factors, and arithmetic operations using loops and conditional statements.
