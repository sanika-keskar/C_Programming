# C Programming – Assignment 15

## Description
This repository contains five C programs based on strings, conditions, and arithmetic calculations.

## Programs Included

1. **Display Name** – Accepts a full name from the user and prints it.
2. **Check Greater Number** – Checks whether a number is greater than 100 or not.
3. **Check Equal Numbers** – Checks whether two numbers are equal or not.
4. **Multiplication of Three Numbers** – Calculates the multiplication of three numbers while ignoring zero values.
5. **Calculate Percentage** – Calculates the percentage using total marks and obtained marks.

## Concepts Covered
- User-defined functions
- Character arrays
- `scanf()` and `printf()`
- Conditional statements (`if-else`)
- Integer and float variables
- Boolean values
- Arithmetic operators
- User input and output

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand strings, comparison operations, conditional statements, and mathematical calculations using C programming.
