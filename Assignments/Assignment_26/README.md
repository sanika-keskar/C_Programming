
C Programming – Assignment 26


Description

This repository contains five C programs focusing on formatting data configurations, raw ASCII translation streams, and symbol sequence tracking.

Programs Included

1. Display ASCII Table (DisplayASCII) – Prints a complete formatted layout containing Symbol, Decimal, Hexadecimal, and Octal formats up to 255.
2. Toggle Single Character (Display) – Toggles a character's case or returns the literal unchanged for structural edge cases.
3. Print Till Z or Reverse Till 'a' (Display) – Displays sequences progressing from an uppercase character to 'Z', or descending from a lowercase letter to 'a'.
4. Check Special Symbol (ChkSpecial) – Targets structural verification of special operators (!, @, #, $, %, ^, &, *).
5. Display Formatted Base Formats (Display) – Receives a standard symbol and shows individual numerical conversions inside format strings.

Concepts Covered

• Format specifiers configuration (%c, %d, %X, %o)
• Iterative index printing
• Range boundary limits execution
• ASCII character conversion offsets
• Decrement sequence chains (ch--)
• Boolean identification parameters

Technologies Used

• Programming Language: C
• Compiler: GCC
• Editor: Visual Studio Code / Visual Studio

How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:bash
gcc filename.c -o output
Use code with caution.
4. Run the program on Windows:bash
.\output.exe
Use code with caution.

Learning Objective

The objective of this assignment is to understand underlying numeric bases for data visualization format flags, study data mapping blocks, and construct custom sequence generation pipelines.
