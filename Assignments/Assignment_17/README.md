# C Programming – Assignment 17

## Description
This repository contains five C programs based on different number and alphabet patterns.

## Programs Included

1. **Continuous Number Pattern** – Displays numbers from 1 to 9 repeatedly.
2. **Even and Odd Pattern** – Displays even and odd numbers in alternate rows.
3. **Alphabet and Number Pattern** – Displays small alphabets and numbers in alternate rows.
4. **Positive and Negative Pattern** – Displays positive and negative numbers in alternate rows.
5. **Increasing Number Pattern** – Displays increasing numbers in each row.

## Concepts Covered
- Nested `for` loops
- User-defined functions
- Conditional statements (`if-else`)
- Number patterns
- Alphabet patterns
- Positive and negative numbers
- Increment operators
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to improve understanding of nested loops and different number and alphabet patterns.
