# C Programming – Assignment 12

## Description
This repository contains five C programs based on digits and number operations.

## Programs Included

1. **Display Digits** – Displays the digits of a number in reverse order.
2. **Check Zero** – Checks whether a given number contains zero or not.
3. **Count Two** – Counts how many times digit 2 appears in a number.
4. **Count Four** – Counts how many times digit 4 appears in a number.
5. **Count Digits Less Than 6** – Counts all digits that are smaller than 6.

## Concepts Covered
- User-defined functions
- `while` loop
- Conditional statements (`if`)
- Integer variables
- Modulus operator (`%`)
- Division operator (`/`)
- Digit extraction
- User input using `scanf()`
- Output using `printf()`

## Technologies Used
- **Programming Language:** C
- **Compiler:** GCC
- **Editor:** Visual Studio Code

## How to Compile and Run

1. Open the assignment folder in Visual Studio Code.
2. Open the terminal.
3. Compile the C file:

   ```bash
   gcc filename.c -o output
   ```

4. Run the program on Windows:

   ```bash
   .\output.exe
   ```

## Learning Objective
The objective of this assignment is to understand digit extraction, digit counting, and number operations using loops in C.
